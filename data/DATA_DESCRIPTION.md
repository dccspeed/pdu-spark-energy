## Obtaining the Data Files

**Note:** The large data files (*.csv.gz) are not included in the git repository to keep it lightweight.

### If you cloned this repository:

The data files are excluded from version control but can be:

1. **Obtained from the original source** (if available)
2. **Regenerated using preprocessing tools** (if you have raw InfluxDB exports)
3. **Requested from the repository maintainer**

### File sizes excluded from git:

- `all_power_standard_processed.csv.gz` - 23.4 MB
- `all_power_light_processed.csv.gz` - 18.3 MB  
- `all_power_heavy_processed.csv.gz` - 48.4 MB

**Total:** ~90 MB of power measurement data

### Regenerating data:

If you have raw PDU data in InfluxDB JSON format or tar.xz archives:

```bash
# Place your archives or raw files in data/
python preprocess_data.py
```

This will automatically:
- Extract archives
- Convert InfluxDB JSON to CSV
- Add headers
- Compress to .csv.gz format
- Generate this metadata
